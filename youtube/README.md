# YouTube — StreamClean uBO

Pour installer les filtres, utilise le **[bouton du README principal](../README.md)** : c'est la méthode la plus simple.

Les règles de [youtube-filters.txt](youtube-filters.txt) sont déjà dans [la liste commune](../filtres-complets.txt). **Ne souscris pas les deux en même temps.**

Ces règles masquent certains emplacements publicitaires de YouTube ; les pubs intégrées aux vidéos dépendent principalement des filtres officiels d'uBlock Origin (notamment **Quick fixes**), à conserver actifs et à jour.

En option, tu peux aussi masquer les [Shorts et cartes de fin](youtube-interface-optionnel.txt). Ce fichier n'est **pas activé par défaut**.

En cas de problème, actualise les listes officielles dans uBlock Origin, puis désactive les filtres personnalisés pour comparer.
